点击一本书开始抽背；鼠标移过会把书抽出来。学习记录按单词保存，换书后同一个词仍然保留。

单词书格式说明

JSON 文件，≤ 2 MB、单本 ≤ 8000 词；按 w 自动去重。必填 name、words[].w、words[].d；可选 description、words[].ph、words[].e。

{
  "format": "ielts-flashcard-book",
  "version": 1,
  "name": "我的单词书",
  "description": "可选",
  "words": [
    {
      "w": "resilient",
      "ph": "/rɪˈzɪliənt/",
      "d": "adj. 有韧性的；能迅速恢复的",
      "e": "a resilient community 有韧性的社区"
    }
  ]
}

短语也可以收录，ph 留空即可。也可以直接下载格式模板，照着填。

单词书保存在本浏览器；建议保留原始 JSON 文件作为备份。
